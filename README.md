# Jitahidi Fitness Centre

Jitahidi is an online website for a fitness center that lets customers preview available services and join in bettering their fitness journey.

## What Jitahidi offers
A simple to use user interface where clients can browse list of available programs and also get in touch with trainers that can assist them in acheiving their goals.
